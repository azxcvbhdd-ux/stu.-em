# دليل الأقسام الداخلية

موقع تعريفي لطلبة كلية البوليتكنيك الهندسية — البصرة، يضم طريقة التسجيل والضوابط وكادر الإشراف الصباحي والمسائي. يدعم إضافته إلى الشاشة الرئيسية بأيقونة شعار الكلية.

## الرفع على GitHub ونشر الموقع

1. فك ضغط الحزمة أولًا.
2. أنشئ مستودعًا على GitHub، مثل `student-dorm-guide`. يمكن استخدام مستودع عام مع خطة GitHub المجانية.
3. من **Add file → Upload files** ارفع جميع محتويات الحزمة إلى جذر المستودع، مع الحفاظ على مجلدي `assets` و`icons`. يجب أن يظهر `index.html` مباشرة في جذر المستودع.
4. اضغط **Commit changes** لحفظ الملفات.
5. افتح **Settings → Pages**.
6. ضمن **Build and deployment**، اجعل **Source** هو **Deploy from a branch**.
7. حدّد الفرع **main**، أو الفرع الذي رفعت إليه الملفات، والمجلد **/(root)**، ثم اضغط **Save**.
8. عند اكتمال النشر، افتح رابط الموقع الظاهر في صفحة **Pages**.

ارفع محتويات ZIP بعد فك الضغط؛ رفع ملف ZIP وحده لا يعرض الموقع. لا يحتاج المشروع إلى تثبيت حزم أو تنفيذ أوامر بناء.

## إضافته كتطبيق مصغّر على الهاتف

بعد نشر الموقع وفتح رابطه الآمن `https://`:

- **Android:** افتح الموقع في Chrome، ثم استخدم **تثبيت التطبيق** أو **الإضافة إلى الشاشة الرئيسية** من قائمة المتصفح، حسب الخيار المتاح.
- **iPhone:** افتح الموقع في Safari، ثم اضغط **مشاركة → إضافة إلى الشاشة الرئيسية**.

تأتي أيقونة التطبيق من شعار الكلية، ويُفتح في نافذة مستقلة في المتصفحات الداعمة. تتضمن الحزمة أيقونات لأندرويد وآيفون وأيقونة صغيرة لتبويب المتصفح. تُحفظ صفحات الدليل وموارده للاستخدام دون اتصال بعد فتح الموقع عبر الإنترنت واكتمال الحفظ. تحتاج الروابط الخارجية، مثل بوابة أور، إلى الإنترنت.

## الملفات

| الملف أو المجلد | المحتوى |
| --- | --- |
| `index.html` | الصفحة الرئيسية وتصميم الموقع ومحتواه وتفاعلاته |
| `assets/` | شعار الكلية والخط العربي المستخدم في الموقع |
| `icons/` | أيقونات التطبيق المصغّر والمتصفح وآيفون |
| `manifest.webmanifest` | اسم التطبيق وشعاره وإعدادات تشغيله |
| `pwa.js` | تفعيل دعم الاستخدام دون اتصال عند النشر |
| `sw.js` | حفظ موارد الموقع للاستخدام دون اتصال |
| `.nojekyll` | نشر الملفات الثابتة مباشرة على GitHub Pages |

للمعاينة على جهازك، افتح `index.html` مع بقاء المجلدات بجانبه. يتطلب تثبيت التطبيق المصغّر نشر الموقع عبر HTTPS أو تشغيله على localhost.

## تصحيح ظهور الشعار

شعار المقدمة والصفحة الرئيسية والبطاقات مدمج داخل HTML، ولا ينتظر تنزيل صورة منفصلة. أزيلت حركة الحلقة حول شعار الصفحة الرئيسية. ارفع جميع محتويات الحزمة، بما فيها sw.js، لاستبدال النسخة السابقة.
